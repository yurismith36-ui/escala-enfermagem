# Escala de Enfermagem — Protótipo V1

Abra `index.html` no navegador.

## O que já funciona
- visual responsivo para celular e computador;
- perfis simulados: enfermeiro responsável, administrador e funcionário;
- criação, edição e remoção de postos;
- publicação da escala;
- janela de 2 horas após a primeira publicação;
- bloqueio automático após 2 horas;
- desbloqueio excepcional pelo perfil administrador;
- registro de falta e substituição;
- histórico local das alterações;
- controle de versão;
- visão individual do funcionário;
- geração de imagem PNG;
- impressão / salvar como PDF pelo navegador;
- persistência local no navegador via localStorage.

## Importante
Esta V1 é um protótipo funcional sem servidor. Não use como sistema oficial de produção ainda. Na próxima etapa, login, permissões, histórico e bloqueio deverão ser validados no servidor/banco de dados.
